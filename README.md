# The Bus Reservation System
The Bus Reservation System is a simple console-based application developed as a first-semester Programming and Problem Solving (CSE 114) project. The main goal of this project is to make the bus ticket booking process easier and more organized through programming. The system allows users to view available buses, check schedules, select seats, and reserve tickets efficiently.

This project was designed and implemented using the programming concepts learned in the PPS course, including variables, conditional statements, loops, functions, arrays, and file handling. Developing this project helped me strengthen my problem-solving skills and gain practical experience in applying programming knowledge to solve a real-world transportation management problem.
